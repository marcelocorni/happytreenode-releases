# Instalar HappyTreeNode 0.1.0-alpha.22.3

1. Encerre o Servidor Local do HTN antes de instalar.
2. Execute `HappyTreeNode-Setup-0.1.0-alpha.22.3-win-x64.exe`. A instalação é por usuário em Windows x64, versão 10 build 17763 ou posterior.
3. Abra HappyTreeNode - Cliente pelo menu Iniciar. O Setup inclui .NET, os workers locais e os modelos/vozes fixados do Kokoro; não requer instalar SDK, Python ou Node.js.
4. Entre em Conta e licença. Configure os serviços externos necessários aos seus workflows.

## Workspace novo, sem migração

O novo padrão é `%LOCALAPPDATA%\happytreenode\workspaces\principal`.

**A pasta anterior `%LOCALAPPDATA%\n8n-de-pobre\workspaces\principal` não é copiada, migrada nem apagada.** O novo workspace recebe os exemplos oficiais, mas não recebe automaticamente os projetos, arquivos, credenciais, estado local da licença ou perfis de navegador da base antiga. Será necessário configurar a nova base ou escolher explicitamente outro workspace.

O Host aceita `N8NP_DATA`; os iniciadores aceitam `-Workspace`. Encerre a instância anterior antes de usar o mesmo workspace ou a mesma porta. A instalação dos executáveis continua em `%LOCALAPPDATA%\Programs\HappyTreeNode`.

Desinstalar remove o programa e seus atalhos e preserva os dados locais. Com o Servidor Local encerrado, a pasta de um workspace pode ser apagada manualmente; isso exclui definitivamente os dados nela contidos.

## Integrações

- Google: habilite as APIs escolhidas no seu projeto Google Cloud, crie uma credencial OAuth Aplicativo para computador e importe o JSON em Projeto → Recursos do projeto → Contas Google. Consulte o guia Google no manual.
- WhatsApp/captura: navegador compatível instalado e sessão autorizada pelo usuário. O monitor de grupos requer sua janela dedicada aberta.
- Access: o driver ACE de 64 bits é necessário somente para esse conector.
- Internet: necessária para cadastro, validação da licença e integrações externas.

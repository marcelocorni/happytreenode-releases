# Instalar HappyTreeNode 0.1.0-alpha.28

1. Encerre o Servidor Local antes de instalar.
2. Execute `HappyTreeNode-Setup-0.1.0-alpha.28-win-x64.exe` em Windows x64, versão 10 build 17763 ou posterior.
3. Abra HappyTreeNode — Cliente pelo menu Iniciar. Inclui runtime .NET, workers e os modelos/vozes fixados do Kokoro; não exige SDK, Python ou Node.js instalados separadamente.
4. Consulte os exemplos 108, 109 e 110/110.2 no Manual e o guia Retomar itens, lotes e workflows filhos. A busca aceita número e variante.
5. Baixe e extraia o ZIP do cenário. Execute Preparar-bases.cmd para criar as duas bases SQLite fictícias, sem instalar um servidor. O preparador preserva arquivos existentes.
6. Cadastre uma conexão SQLite para recuperacao-pendente.db e selecione-a no nó Consultar SQL com dados. No 110, configure e salve o filho 110.2 e execute somente o principal 110.
7. Após a falha intencional no pedido 3, edite a MESMA conexão para recuperacao-pronta.db. No histórico, confirme e use Retomar execução. Executar workflow inicia outra execução.

## Dados e compatibilidade

Workspace padrão: `%LOCALAPPDATA%\happytreenode\workspaces\principal`. Executáveis: `%LOCALAPPDATA%\Programs\HappyTreeNode`. A pasta antiga n8n-de-pobre não é copiada, migrada ou apagada automaticamente. A desinstalação preserva os dados locais. Faça backup dos seus projetos.

Versão cumulativa, API de plugins 45, compatibilidade de dados 1. Todos os 258 nós anteriores continuam disponíveis; 110 cenários e 175 workflows em 25 plugins. Os quatro novos workflows foram homologados pelo usuário.

## Recuperação e limites

Checkpoints de formato 2 preservam etapas prontas e posições de itens/lotes. Chamadas filhas continuam com o mesmo ID, entrada e versão original; retome pela execução principal. Chamadas concluídas reutilizam a saída. O histórico mostra progresso e tentativas.

Há até três retomadas manuais. Uma etapa pendente com efeitos externos incertos continua bloqueada; não é repetida automaticamente. As restrições dos checkpoints antigos de formato 1 são preservadas, sem recuperar itens retroativamente. Versões originais dos plugins, arquivos íntegros e conteúdo dentro da retenção continuam necessários.

A leitura retomada pode observar o estado atual do serviço externo. Retomada não substitui transações ou conferência. Sessões HTTP com cookies permanecem temporárias por tentativa. Serviço Windows, Assistente de IA e atualização automática continuam adiados.

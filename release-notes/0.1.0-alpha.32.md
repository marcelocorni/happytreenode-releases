# HappyTreeNode 0.1.0-alpha.32

- **Preparar imagem** redimensiona ou recorta JPEG e PNG e gera um novo PNG.
- **Registrar classificador de imagens ONNX** registra uma versão local com classes, dimensões, layout e normalização, após validar o modelo.
- **Classificar imagem** executa em CPU e retorna classe, score, alternativas e indicação configurável para revisão.
- **117 e 118** demonstram a classificação de uma foto e o processamento de uma pasta com exportação CSV. Modelo e fotos sintéticas acompanham o manual offline.

O pacote Windows x64 contém 267 nós, 118 cenários e 191 workflows de exemplo. O catálogo numérico do ML mantém seus contratos. A classificação de imagens aceita um perfil ONNX específico. Consulte **Classificação local de imagens** no manual para os limites e os parâmetros compatíveis.

Os exemplos 117 e 118 foram homologados em 10/11/2026.

# HappyTreeNode 0.1.0-beta.7

- Gerador de CRUD portátil para SQL Server, com editor visual, relacionamentos e painel.
- Campos obrigatórios configuráveis nos CRUDs SQL Server, PostgreSQL, Excel local e Google Planilhas.
- Domínios nomeados para reutilizar a mesma lista de valores em vários campos. O aplicativo valida as opções e a obrigatoriedade ao salvar.
- Exemplo 138 com clientes, produtos e pedidos no SQL Server. O manual inclui a configuração do Studio e do aplicativo gerado.

O exemplo 138 foi homologado. Na beta.6, use **Conta e licença → Verificar atualizações**. Versões beta anteriores recebem os pacotes em sequência. Para uma instalação nova ou a partir da alpha.37, use o Setup completo.

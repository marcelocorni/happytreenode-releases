# HappyTreeNode 0.1.0-alpha.6

Conecte APIs com arquivos e consultas paginadas, e compartilhe relatórios no tema escolhido.

- **Relatórios em Claro ou Escuro:** o HTML exportado acompanha o tema do Studio. Também é possível fixar o tema no próprio nó, inclusive para execuções agendadas. Inclui gráficos interativos, tabelas e versão estática offline.
- **Enviar arquivos HTTP:** envie de um a 16 arquivos do projeto como multipart, com campos de texto e credenciais de API por projeto. Os nomes dos arquivos são preservados.
- **Consultar API paginada:** reúna dados por página, deslocamento, cursor ou próxima URL. A variante com dados recebe parâmetros de outros nós. Limites e falhas interrompem a consulta sem publicar uma lista parcial.
- **Exemplos 41 e 42:** API fictícia local para testar consulta paginada, painel e envio de relatório com metadados. Workflows, fontes e instruções disponíveis no Manual.
- **Compatibilidade com PDF:** o conversor aceita relatórios estáticos nos dois temas.
- Catálogo com **144 nós, 42 cenários e 60 workflows de exemplo**.

## Atualizar

Encerre o **Servidor Local**, execute o novo Setup e mantenha a pasta de instalação. Projetos, arquivos, credenciais e perfis do navegador ficam separados do programa e são preservados. Depois, abra **HappyTreeNode - Cliente**.

Para experimentar os exemplos 41/42, baixe o ZIP pelo Manual, extraia e execute **Iniciar-api-exemplos.cmd**. Mantenha essa janela aberta durante o teste e encerre-a com Ctrl+C ao terminar. O serviço usa dados fictícios e não precisa de conta externa.

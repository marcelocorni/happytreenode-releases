# HappyTreeNode 0.1.0-beta.11

- Use chaves primárias de até oito colunas e selecione relacionamentos pelo nome nos CRUDs de PostgreSQL, SQL Server, MySQL e MariaDB.
- Cadastre pedidos e itens na mesma tela. A lista de produtos acompanha a empresa do cliente e os registros são gravados juntos.
- Use as opções do ENUM nativo do PostgreSQL, MySQL e MariaDB. No SQL Server, configure os domínios pelo editor.
- Confira tabelas, chaves, tipos, vínculos e permissões de leitura antes de exportar.
- Campos numéricos bloqueiam letras digitadas ou coladas e verificam intervalo e casas decimais. Use ponto nos decimais.
- Nos exemplos 142 a 142.4, selecione a empresa pelo nome. O banco atribui códigos e números de pedidos. O manual inclui os SQLs e as etapas de teste.

Os exemplos 142 a 142.4 e a validação dos campos numéricos foram homologados. O catálogo tem 278 nós, 142 cenários e 222 workflows de exemplo.

Quem usa a beta.10 pode atualizar em **Conta e licença → Verificar atualizações**. Betas anteriores recebem os pacotes intermediários em sequência. Para uma instalação nova ou a partir da alpha.37, use o Setup completo. Gere novamente os CRUDs existentes para incorporar as melhorias.

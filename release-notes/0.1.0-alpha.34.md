# HappyTreeNode 0.1.0-alpha.34

- **Buscar arquivos no Google Drive** tem um modo de paginação automática. A saída traz lotes de até 100 arquivos, totais e avisos quando há outra página ou o Drive retorna uma busca incompleta.
- **Exportar documento Google** usa o título do documento e a extensão do formato escolhido quando **Nome local** está vazio. Para definir outro nome, preencha o campo.
- **Execuções** mostra o nome do arquivo e a posição na repetição quando disponíveis. Downloads HTTP mostram o código da resposta. **Gravar arquivo na pasta** distingue conflitos de nome e erros de permissão.
- Exemplos **121**, **122** e **123** no manual e no projeto de demonstração. Cobrem mais de 100 PDFs, exportação de Docs e Planilhas e falha no último item de um lote.

Os cenários 121, 122 e 123 foram homologados. A alpha.34 reúne **270 nós, 123 cenários e 196 workflows de exemplo**. O instalador inclui o manual offline.

# HappyTreeNode 0.1.0-alpha.16

## Conciliação e tratamento de falhas

- **Comparar tabelas** concilia duas fontes por chave e classifica cada pedido ou registro como Só em A, Só em B, Igual ou Diferente. O resultado conserva os valores dos dois lados e identifica os campos divergentes.
- **Falhar com mensagem** encerra o workflow quando um caminho de validação é alcançado. O código e a mensagem ficam no histórico da execução.
- **Workflow de erro** vincula um tratador do mesmo projeto. O tratador recebe um diagnóstico em JSON e aparece nas execuções vinculadas. Retomar o mesmo ID preserva o registro do primeiro tratamento.

## Exemplo e manual

O cenário 65 compara um CSV com uma base SQLite fictícia, gera um painel e um CSV de conferência, aplica uma regra de validação e registra a falha em um workflow separado. O manual inclui o roteiro para cadastrar a conexão local, vincular o tratador e conferir os resultados.

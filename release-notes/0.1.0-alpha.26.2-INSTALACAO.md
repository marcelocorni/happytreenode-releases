# Instalar HappyTreeNode 0.1.0-alpha.26.2

1. Encerre o Servidor Local antes de instalar.
2. Execute `HappyTreeNode-Setup-0.1.0-alpha.26.2-win-x64.exe` em Windows x64, versão 10 build 17763 ou posterior.
3. Abra HappyTreeNode — Cliente pelo menu Iniciar. O Setup inclui .NET, workers locais e os modelos/vozes fixados do Kokoro; não exige SDK, Python ou Node.js instalados separadamente.
4. Consulte os exemplos 98–104.2 no manual: Firebird, PostgreSQL hospedado, MongoDB, conjuntos em disco, expressões e calendário. Os exemplos aparecem em ordem numérica natural, incluindo 100 após 99 e suas variantes.
5. Configure suas próprias conexões antes de executar os exemplos de bancos. Os servidores de homologação do desenvolvimento não fazem parte do instalador.

## Dados existentes

O workspace padrão permanece em `%LOCALAPPDATA%\happytreenode\workspaces\principal`; os executáveis em `%LOCALAPPDATA%\Programs\HappyTreeNode`.
Não há nova migração. A pasta antiga `%LOCALAPPDATA%\n8n-de-pobre\workspaces\principal` não é copiada, migrada ou apagada automaticamente.
Desinstalar preserva os dados locais. Mantenha backup dos seus projetos e encerre as instâncias anteriores antes de usar o mesmo workspace/porta.
A versão é cumulativa e mantém os nós anteriores. API de plugins 44, compatibilidade de dados 1.

## Integrações

Firebird e MongoDB devem estar disponíveis na sua rede ou no provedor escolhido. MongoDB Atlas utiliza o mesmo conector MongoDB. Supabase, Neon, Aiven e Layerbase utilizam o conector PostgreSQL e as credenciais do próprio usuário; selecione o serviço PostgreSQL no provedor.
TLS, certificados, permissões e limites continuam sujeitos à conta e ao serviço contratado. Não é necessário instalar esses bancos junto com o HTN.
Escritas exigem autorização na conexão. Confira chaves/filtros e use dados de teste antes de alterar sua base.
A correção PostgreSQL encerra o leitor antes do commit na consulta para conjunto em disco; o workflow 99 pode ser executado novamente após a instalação.
Cadastro, licença e serviços externos exigem internet. Credenciais e dados privados não integram este pacote.

# Instalação — HappyTreeNode 0.1.0-alpha.8

## Primeira instalação

1. Baixe `HappyTreeNode-Setup-0.1.0-alpha.8-win-x64.exe` pela release oficial: https://github.com/marcelocorni/happytreenode-releases/releases/tag/v0.1.0-alpha.8.
2. Execute o Setup no Windows de 64 bits e siga as instruções. Os atalhos permitem abrir o Cliente, o Servidor Local e a desinstalação.
3. Inicie o Servidor Local e abra **HappyTreeNode - Cliente**. O endereço local normalmente é `http://127.0.0.1:5078`.
4. Em **Conta e licença**, entre com a conta cadastrada no Portal. O uso exige avaliação ou licença válida. O mesmo usuário pode manter uma sessão ativa do Servidor Local.
5. Abra o projeto **Exemplos HappyTreeNode** e consulte o Manual pelo botão do aplicativo.

## Atualização

Encerre o **Servidor Local** antes de executar o instalador. Fechar apenas o navegador não encerra o servidor. Mantenha a pasta de instalação anterior e siga o Setup; os projetos, arquivos, credenciais e perfis do navegador ficam separados do programa e são preservados.

Se desejar, use o backup do workspace antes da atualização. A restauração do backup é destinada à instalação original; a transferência entre computadores deve usar a exportação/importação de workflows e a reconfiguração dos recursos necessários.

As versões são cumulativas. Não é necessário instalar todas as versões intermediárias. Esta release inclui os recursos da alpha.7.

## Conferir o instalador

No PowerShell, execute na pasta do download:

```powershell
Get-FileHash .\HappyTreeNode-Setup-0.1.0-alpha.8-win-x64.exe -Algorithm SHA256
```

Compare o resultado com:

```text
e44eab02a526fa6c6def030fda7018af8bb44213a13afe73984c1c7faadb722b
```

O arquivo tem **295.392.715 bytes**. O checksum e o manifesto da mesma release contêm esses dados.

## Experimentar os novos recursos

- **Exemplo 46:** configure SMTP e cotas, use destinatários autorizados, aprove cada mensagem para a fila, crie uma campanha e inicie a fila. O histórico conserva os itens processados.
- **Exemplo 47:** selecione uma conta IMAP e uma chave exclusiva. Em Somente futuras, a primeira execução estabelece o ponto inicial; depois receba um e-mail e execute novamente. Cada mensagem capturada gera um TXT.
- **Exemplo 48:** selecione a conta em Ler e-mail IMAP e salve o workflow. Em Gatilhos, escolha Chegada de e-mail IMAP com a mesma conta e pasta. Salve pausado, confira e ative. Uma nova mensagem correspondente inicia uma execução automaticamente.

Mantenha o Servidor Local em execução para filas e gatilhos. Configure intervalos e cotas permitidos pelo provedor. Rascunhos dos exemplos são preparados para revisão; a execução do desenho não autoriza automaticamente esses envios. As credenciais não acompanham workflows exportados e precisam ser cadastradas no projeto.

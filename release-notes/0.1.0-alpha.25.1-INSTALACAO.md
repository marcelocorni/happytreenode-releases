# Instalar HappyTreeNode 0.1.0-alpha.25.1

1. Encerre o Servidor Local antes de instalar.
2. Execute `HappyTreeNode-Setup-0.1.0-alpha.25.1-win-x64.exe`. A instalação é por usuário em Windows x64, versão 10 build 17763 ou posterior.
3. Abra HappyTreeNode — Cliente pelo menu Iniciar. O Setup inclui .NET, workers locais e os modelos/vozes fixados do Kokoro.
4. Abra os exemplos 92–97 e consulte o guia Diagramas e planejamento no manual. Para PNG, SVG e PDF, tenha Edge ou Chrome instalado.
5. Execute novamente os workflows com acentos que você gerou antes do corretivo. O histórico anterior permanece disponível.

## Dados existentes

O workspace padrão continua em `%LOCALAPPDATA%\happytreenode\workspaces\principal`; os executáveis em `%LOCALAPPDATA%\Programs\HappyTreeNode`.
Não há nova migração de banco. A pasta antiga `%LOCALAPPDATA%\n8n-de-pobre\workspaces\principal` não é copiada, migrada ou apagada automaticamente.
Desinstalar preserva os dados locais. Mantenha backup dos seus projetos e encerre as instâncias anteriores antes de usar o mesmo workspace/porta.

## Integrações

Os exemplos 97.3–97.6 exigem contas e destinos próprios. Configure os canais e revise os dados antes do envio. Aceite pelo SMTP não confirma entrega ao destinatário.
Leitura de esquema consulta metadados com as permissões da conexão. A geração de diagramas não consulta os registros das tabelas.
Cadastro, licença e serviços externos exigem internet. A geração dos diagramas e arquivos é local; não exige API de IA.

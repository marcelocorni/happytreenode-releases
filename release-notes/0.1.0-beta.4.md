# HappyTreeNode 0.1.0-beta.4

- O nó Gerar CRUD Excel local transforma as abas selecionadas de um XLSX em cadastros de um aplicativo portátil para Windows x64.
- O aplicativo grava em dados.xlsx, uma cópia da planilha incluída na pasta exportada. Os formulários permitem vínculos entre abas e seleção por nome.
- Os modelos Cadastro e Painel e cadastros incluem personalização de marca e gráficos interativos. O exemplo 135 usa as abas Clientes, Produtos e Pedidos.
- O formulário sugere o próximo ID para chaves inteiras do Excel, começando em 1 nas abas vazias.
- O CRUD gera seletores a partir de listas suspensas do Excel e valida as opções ao salvar. No exemplo 135, Status oferece confirmado, cancelado e aberto.
- Os CRUDs Excel e PostgreSQL permitem filtrar opções dos relacionamentos. O exemplo 135 oferece apenas produtos ativos ao criar pedidos.
- O manual ensina a configurar os cabeçalhos, as chaves, os tipos e os relacionamentos.

O exemplo 135 foi homologado. Quem usa a beta.3 pode atualizar em **Conta e licença → Verificar atualizações**. A beta.1 e a beta.2 recebem as versões intermediárias em ordem. Para instalação nova ou migração da alpha.37, use o Setup completo. Encerre o Servidor Local antes de executar o Setup na mesma pasta de instalação.

# Instalar HappyTreeNode 0.1.0-alpha.27

1. Encerre o Servidor Local antes de instalar.
2. Execute `HappyTreeNode-Setup-0.1.0-alpha.27-win-x64.exe` em Windows x64, versão 10 build 17763 ou posterior.
3. Abra HappyTreeNode — Cliente pelo menu Iniciar. Inclui runtime .NET, workers e os modelos/vozes fixados do Kokoro; não exige SDK, Python ou Node.js instalados separadamente.
4. Consulte os exemplos 105–107.3 no Manual. A busca aceita números e variantes como 107 e 107.2.
5. Baixe e extraia o ZIP do cenário. Abra Iniciar-api-alpha27.cmd e mantenha a janela aberta enquanto testa. A API didática utiliza Windows PowerShell, dados fictícios e somente 127.0.0.1:8096, sem conta externa. Feche a janela ao terminar.

## Dados e compatibilidade

Workspace padrão: `%LOCALAPPDATA%\happytreenode\workspaces\principal`. Executáveis: `%LOCALAPPDATA%\Programs\HappyTreeNode`. A pasta antiga n8n-de-pobre não é copiada, migrada ou apagada automaticamente. A desinstalação preserva os dados locais. Faça backup dos seus projetos.

Versão cumulativa, API de plugins 45, compatibilidade de dados 1. Nós antigos continuam disponíveis; sessão HTTP e seguir redirects ficam desligados por padrão.

## Novos recursos

Sessões compartilham cookies somente entre nós da mesma tentativa, com mesmo nome/origem/credencial. Fim, falha, cancelamento, pausa persistente, retomada e reinício encerram a memória. Workflows filhos não herdam a sessão.

Redirecionamentos opcionais somente GET/HEAD na mesma origem, até dez saltos; escritas/uploads não são redirecionados. Paginação em disco entrega .htntable para transformação e exportação. Uma página até 2 MiB; conjunto até 2 milhões de linhas/256 MiB, até 10.000 páginas e uma hora, respeitando seus limites configurados.

Use credenciais protegidas para serviços reais; não salve senhas em parâmetros do desenho. O corpo de uma API pode conter dados sensíveis. Confira conteúdo antes de compartilhar.
Atualizador automático permanece no backlog; esta distribuição usa Setup completo.

# Instalar HappyTreeNode 0.1.0-alpha.31

1. Encerre o Servidor Local antes de instalar.
2. Execute `HappyTreeNode-Setup-0.1.0-alpha.31-win-x64.exe` no Windows x64, versão 10 build 17763 ou posterior.
3. Abra **HappyTreeNode — Cliente** pelo menu Iniciar.
4. No manual, busque **115** para converter DOCX ou **116** para gerar e validar PDF/A-2b.
5. Ative **Usar o nome do DOCX** nas propriedades de um dos conversores para reaproveitar o nome do arquivo de entrada.

Os motores locais de conversão e validação vêm no instalador. Para ver os exemplos e os limites dos arquivos, abra o guia **DOCX para PDF e arquivamento PDF/A** no manual.

O workspace padrão fica em `%LOCALAPPDATA%\happytreenode\workspaces\principal`. Faça backup dos projetos antes de atualizar.

# Instalar HappyTreeNode 0.1.0-alpha.33

1. Encerre o Servidor Local antes de instalar.
2. Execute `HappyTreeNode-Setup-0.1.0-alpha.33-win-x64.exe` no Windows x64, versão 10 build 17763 ou posterior.
3. Abra **HappyTreeNode — Cliente** pelo menu Iniciar.
4. Busque **119** no manual para configurar uma pasta FTP/FTPS e salvar os arquivos do lote.
5. Abra **120** para testar o download a partir de uma lista de URLs. O material inclui um servidor HTTP local de demonstração.

O workspace padrão fica em `%LOCALAPPDATA%\happytreenode\workspaces\principal`. Faça backup dos projetos antes de atualizar.

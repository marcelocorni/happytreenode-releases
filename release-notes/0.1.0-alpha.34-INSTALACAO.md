# Instalar HappyTreeNode 0.1.0-alpha.34

1. Encerre o Servidor Local antes de instalar.
2. Execute `HappyTreeNode-Setup-0.1.0-alpha.34-win-x64.exe` no Windows x64, versão 10 build 17763 ou posterior.
3. Abra **HappyTreeNode — Cliente** pelo menu Iniciar.
4. Use o exemplo **121** para baixar mais de 100 PDFs de uma pasta do Drive e o **122** para exportar Docs e Planilhas com seus nomes originais.
5. Use o **123** para ver no histórico qual arquivo falhou depois de duas gravações concluídas.

O workspace padrão fica em `%LOCALAPPDATA%\happytreenode\workspaces\principal`. Faça backup dos projetos antes de atualizar.

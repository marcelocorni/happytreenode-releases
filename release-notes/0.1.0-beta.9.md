# HappyTreeNode 0.1.0-beta.9

- Filtros combinados por campos nos CRUDs PostgreSQL, SQL Server, MySQL, MariaDB, Excel local e Google Planilhas.
- Ordenação pelos cabeçalhos e páginas com 25, 50 ou 100 registros, mantendo os filtros na navegação.
- Exportação CSV dos resultados filtrados com as colunas visíveis e a ordenação escolhida.
- Configuração visual dos campos disponíveis para filtrar e ordenar.
- Pesquisa de workflows por nome e número de exemplo no seletor do Studio.
- Exemplo 140 com 160 pedidos fictícios e manual atualizado.

O exemplo 140 e a busca de workflows foram homologados. Quem usa a beta.8 pode atualizar em **Conta e licença → Verificar atualizações**. Betas anteriores recebem os pacotes em sequência. Para uma instalação nova ou a partir da alpha.37, use o Setup completo.

Gere novamente os aplicativos CRUD já exportados para receber os novos controles. O CSV exporta todos os resultados filtrados, com limite de 128 MiB ou dois minutos.

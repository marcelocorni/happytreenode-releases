# HappyTreeNode 0.1.0-beta.12

- Preço sugerido e editável nos pedidos dos CRUDs PostgreSQL, SQL Server e MySQL. O editor permite escolher o vínculo e a coluna de origem. O preço gravado permanece no item ao reabrir pedidos.
- Nomes nos vínculos das listagens, com identificação pela chave completa.
- Destaque do item recusado e do campo quando identificado. Os dados do formulário são preservados para correção e a gravação permanece conjunta.
- Reexportação de CRUDs relacionais na mesma pasta, com preservação do `appsettings.Local.json`.
- Exemplo 143 com variantes para PostgreSQL, SQL Server e MySQL e manual atualizado. Catálogo com 278 nós, 143 cenários e 225 workflows.

Os exemplos 143, 143.2 e 143.3 e a reexportação foram homologados.

Quem usa a beta.11 pode atualizar em **Conta e licença → Verificar atualizações**. Betas anteriores recebem os pacotes intermediários em sequência. Para instalação nova, use o Setup completo.

Para atualizar um CRUD existente, feche `Iniciar.exe`, mantenha a pasta e a subpasta no nó e ative **Reexportar na mesma pasta**. O aplicativo continua usando a configuração local.

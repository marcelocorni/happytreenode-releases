# HappyTreeNode 0.1.0-alpha.33

- Os botões **+** do canvas abrem uma lista pesquisável de nós compatíveis ao lado da porta clicada. Escolher uma opção adiciona e conecta o nó em uma ação.
- Entradas com múltiplas conexões aceitam novos nós até o limite. A conexão entra depois das anteriores. Cada saída de **Condição** e **Escolher caminho (Switch)** tem seu próprio botão. Uma saída já conectada pode ganhar outros destinos.
- Biblioteca de nós, Configuração e Execuções abrem e recolhem com uma transição curta. A preferência de movimento reduzido do sistema desativa essas transições.
- O manual mostra como montar um workflow pelo canvas usando os botões de conexão rápida.
- **Baixar arquivo do Google Drive** usa o nome original quando **Nome local** fica vazio. O download grava em disco e aceita até 100 MiB por arquivo.
- **Listar arquivos FTP/FTPS** fornece os caminhos relativos dos arquivos para uma repetição. **Carregar arquivo FTP/FTPS do item** e **Baixar arquivo HTTP do item** recebem o JSON de cada item e gravam em disco, com limite de 100 MiB por arquivo. Os exemplos 119 e 120 mostram os dois lotes e ligam a gravação dos arquivos diretamente ao fim da repetição. O manual explica como usar PDFs nos dois fluxos.
- PDFs com nome original sem .pdf recebem o sufixo ao baixar do Drive. Gravar arquivo na pasta também completa o sufixo de um PDF já baixado quando o nome local fica vazio.

A alpha.33 reúne **270 nós, 120 cenários e 193 workflows de exemplo**. Os exemplos 119 e 120 foram homologados com PDFs. O instalador Windows x64 inclui o manual offline.

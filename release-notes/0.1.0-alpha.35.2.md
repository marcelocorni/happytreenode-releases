# HappyTreeNode 0.1.0-alpha.35.2

Atualização automática incremental no Windows, homologada com o workflow 121. O pacote ficou preparado durante a execução. O HTN concluiu e gravou os 105 PDFs antes de reiniciar o Servidor Local e mostrar a nova versão no Studio.

- Em **Conta e licença**, veja a versão instalada e antecipe a consulta de atualizações.
- O Setup completo inclui o atualizador para instalações novas e para quem vem de uma versão anterior à alpha.35. Atualizações compatíveis pelo Studio baixam os arquivos alterados.
- O atualizador verifica a integridade do ZIP, espera a operação em andamento e reinicia na mesma porta e com o mesmo workspace. Se houver rascunho aberto, a aba espera o salvamento. Se o novo servidor falhar ao iniciar, o supervisor volta à versão anterior.
- Esta edição oferece o Setup Windows x64 e o ZIP de homologação para instalações alpha.35.1. O catálogo contém 270 nós, 123 cenários e 196 workflows de exemplo.

# Instalar HappyTreeNode 0.1.0-alpha.32

1. Encerre o Servidor Local antes de instalar.
2. Execute `HappyTreeNode-Setup-0.1.0-alpha.32-win-x64.exe` no Windows x64, versão 10 build 17763 ou posterior.
3. Abra **HappyTreeNode — Cliente** pelo menu Iniciar.
4. No manual, busque **117** para classificar uma foto. O exemplo registra o modelo de demonstração no projeto.
5. Abra **118** no mesmo projeto e use o modelo registrado para classificar uma pasta de fotos e exportar o CSV.

O workspace padrão fica em `%LOCALAPPDATA%\happytreenode\workspaces\principal`. Faça backup dos projetos antes de atualizar.

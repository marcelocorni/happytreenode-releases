# HappyTreeNode 0.1.0-alpha.13.3

- MySQL passa a oferecer TLS obrigatório, mantendo a conexão criptografada quando a hospedagem usa um certificado que não permite validação completa. O modo com certificado verificado continua sendo o padrão; não há troca automática para modos menos restritivos.
- A tela de conexões explica a diferença entre os modos e restaura o padrão ao trocar o tipo de banco.
- Workflows importados podem salvar os vínculos ainda pendentes, mantendo a exigência de configurá-los antes de executar.
- Nós de WhatsApp oferecem Foto com legenda para PNG, JPEG e WebP. Documento permanece como padrão, preservando workflows e rascunhos anteriores.
- Fotos cadastradas com tipo genérico são reconhecidas pelo conteúdo antes de preparar a notificação, preservando as referências dos arquivos.
- Corretivo cumulativo da alpha.13.2. Sem alteração do catálogo, dos workflows de exemplo ou da compatibilidade de dados.

Encerre o Servidor Local antes de instalar na pasta existente. Projetos, arquivos, credenciais e perfis são preservados.

## Instalar ou atualizar

Baixe o Setup desta release, encerre o **Servidor Local** e instale na pasta existente. Projetos, arquivos, credenciais e perfis são preservados. Fechar somente a aba do navegador não encerra o servidor.

O uso exige cadastro e avaliação ou licença válida. Esta versão é cumulativa: **160 nós, 57 cenários e 78 workflows de exemplo**, API de plugins 33 e compatibilidade dos dados locais 1.

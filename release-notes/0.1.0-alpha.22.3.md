# HappyTreeNode 0.1.0-alpha.22.3

Atualização cumulativa para Windows x64: inclui os recursos da alpha.20, os incrementos de recuperação/dados/documentos da alpha.21 e a integração Google da alpha.22, com as correções posteriores.

## Google por APIs

- 26 nós para Drive, Planilhas, Docs, Apresentações, Forms e Classroom, com contas separadas por projeto, OAuth desktop e renovação protegida de tokens.
- Seleção dos serviços e permissão de gravação por conexão. O cliente utiliza seu próprio projeto Google Cloud e importa o JSON de uma credencial do tipo Aplicativo para computador.
- Exemplos 81 a 86, manual atualizado, correções de conclusão OAuth e sequência Gravar → Formatar → Ler no exemplo 82.
- A tela Contas Google diferencia contas salvas, nova conexão e reconexão. Reconectar carrega os serviços salvos, incluindo Classroom, e o acesso de consulta/gravação. Testar conta não altera essas opções.
- Os dois nós anteriores de Forms pelo navegador continuam disponíveis.

## Editor, dados e documentos

- Cores de destaque, fundo e texto dos nós; fundo e texto dos post-its, com opção de recolher/expandir. A apresentação acompanha o workflow ao salvar, exportar e importar.
- Recuperação configurável de horários perdidos após reinício, ordenação de conjuntos em disco e proxy por conta de API.
- Markdown para HTML e PDF, com exemplos 77 a 80. Inclui a correção do script de proxy do exemplo 79 para Windows PowerShell 5.1.

Catálogo: **229 nós, 86 cenários e 121 workflows de exemplo**, distribuídos em 22 plugins. API de plugins 40, compatibilidade de dados 1. O Setup inclui o Kokoro e suas três vozes fixadas.

## Atenção ao novo diretório de dados

**Esta versão muda o workspace padrão para `%LOCALAPPDATA%\happytreenode\workspaces\principal`, sem migração ou cópia automática.**

A base anterior em `%LOCALAPPDATA%\n8n-de-pobre\workspaces\principal` permanece intacta. A pasta nova recebe os exemplos oficiais, sem os projetos, arquivos, credenciais, licença local ou sessões de navegador da base anterior. Caminhos explícitos de workspace continuam aceitos. A desinstalação preserva os dados locais.

Encerre o Servidor Local antes de executar o instalador. Consulte `INSTALACAO.md` para os requisitos e os detalhes dessa mudança.

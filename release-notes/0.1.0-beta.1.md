# HappyTreeNode 0.1.0-beta.1

Primeira beta do HappyTreeNode para Windows x64, baseada na alpha.37.

- O Studio mostra a linha da versão instalada. O atualizador aceita pacotes entre versões beta e mantém as verificações de integridade e a espera pelo fim da execução em andamento.
- Para atualizar a alpha.37, feche o Servidor Local e execute o Setup completo da beta.1 na mesma pasta de instalação. O workspace fica separado dos arquivos do programa.
- A instalação inclui 273 nós, 133 cenários e 206 workflows de exemplo. Consulte o Manual em **Primeiros passos** para executar o primeiro workflow.

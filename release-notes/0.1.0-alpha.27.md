# HappyTreeNode 0.1.0-alpha.27

HTTP com sessões por tentativa de execução, redirecionamentos controlados e coleta de APIs paginadas em disco. Versão cumulativa; mantém os nós, projetos, arquivos e workflows anteriores.

- Sessão HTTP opcional nos nós de requisição, download, upload e paginação. Cookies compartilhados apenas pelo mesmo nome/origem/credencial na tentativa atual. O padrão vazio preserva os workflows anteriores.
- Limpar sessão HTTP: descarta os cookies locais da combinação informada, com entrada JSON opcional para ordenar a etapa no desenho. Não chama a API nem faz logout remoto.
- Redirecionamentos GET/HEAD 301/302/303/307/308, quando habilitados, limitados à mesma origem e a até dez saltos. Ciclos, mudanças de origem e Location inválido falham antes da próxima chamada. Escritas e uploads não acompanham redirecionamentos.
- API paginada em disco e sua variante com dados: até 32 colunas por JSON Pointer, com tipos e regras de ausentes/nulos. Entregam conjunto .htntable v1 para as transformações e exportações existentes.
- Coleta com uma página por vez, até 2 MiB por página. Conjunto até 2 milhões de linhas e 256 MiB, até 10.000 páginas e prazo de uma hora. Falhas, cancelamento e limites não publicam arquivo parcial. Os nós paginados JSON anteriores mantêm seus próprios limites.

Busca do Manual inclui o número do cenário, com ou sem zero inicial, e os nomes dos workflows/variantes, como 107.2. Pesquisas por título e área continuam disponíveis.

Exemplos 105–107, com sete workflows: login e limpeza de cookies, seguir ou inspecionar redirecionamentos, agrupamento em disco, consulta protegida pela sessão e coleta de 25 mil registros. Os ZIPs incluem um servidor didático para Windows PowerShell, somente loopback, sem conta externa. Manual e guia de HTTP/escala atualizados.

Os sete exemplos foram executados pelo motor real com a API didática. A coleta de 25 mil itens gerou um conjunto de aproximadamente 8 MB, acima do limite agregado dos nós JSON. Conferidos 1.051 arquivos históricos de exemplos sem alterações. 198 testes da interface aprovados. A validação técnica e as limitações ficam discriminadas na continuidade da candidata.

Catálogo: 258 nós, 25 plugins, 107 cenários e 171 workflows. Plugin HTTP 0.4.0; API de plugins 45; compatibilidade de dados 1. Os contratos anteriores continuam suportados. Runtime, workers e os modelos/vozes fixados do Kokoro incluídos.

Cookies não são duráveis: fim, falha, cancelamento, pausa persistente, retomada e reinício encerram a memória da sessão. Workflows filhos não a herdam. O HTN não copia cookies para os resultados; o corpo da própria API pode conter dados sensíveis. Não há snapshot automático entre páginas.

Windows x64. Encerre o Servidor Local antes de instalar e mantenha seu workspace. Atualização automática/incremental pelo aplicativo permanece no backlog. Os sete workflows 105–107.3 e a pesquisa numérica do Manual foram homologados pelo usuário. Publicação autorizada em 09/11/2026.

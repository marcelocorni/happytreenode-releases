# HappyTreeNode 0.1.0-beta.16

- Prévia de importação de workflows com seleção de conexões de banco, contas Google e fontes de arquivos do projeto de destino.
- Resumo por workflow com atalhos para abrir os nós com vínculos pendentes. As chamadas de um pacote continuam ligadas às novas cópias.
- Exemplo 147 com um workflow principal e um auxiliar, uma base SQLite e uma fonte JSON.
- Manual offline atualizado, Setup completo Windows x64 e atualização incremental da beta.15.

O exemplo 147 foi homologado. O manual reúne 279 nós, 147 cenários e 232 workflows.

Quem usa a beta.15 pode atualizar em **Conta e licença → Verificar atualizações**. Betas anteriores recebem os pacotes intermediários em ordem. Para uma instalação nova, use o Setup completo para Windows x64.

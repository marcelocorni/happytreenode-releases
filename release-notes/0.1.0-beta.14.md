# HappyTreeNode 0.1.0-beta.14

- Os CRUDs portáteis de SQL Server e MySQL ganharam login opcional, contas individuais e permissões por perfil e cadastro.
- A auditoria registra quem alterou cada cadastro. A gravação de um pedido com itens e de seu evento de auditoria usa a mesma transação.
- A reexportação na mesma pasta preserva a conexão local, as contas e o histórico de auditoria.
- Os exemplos 145 (SQL Server) e 145.2 (MySQL) foram homologados. O manual reúne 145 cenários e 228 workflows.

Quem usa a beta.13 pode atualizar em **Conta e licença → Verificar atualizações**. Betas anteriores recebem os pacotes intermediários em sequência. Para instalação nova, use o Setup completo do Windows x64.

Nos exemplos 145 e 145.2, gere o app e execute o `Preparar-acesso.sql` no mesmo banco dos dados. Abra `Iniciar.exe` para obter o código de criação do primeiro administrador. O recurso de login no MySQL exige versão 8.0.16 ou posterior e tabelas InnoDB.

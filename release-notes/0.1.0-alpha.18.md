# HappyTreeNode 0.1.0-alpha.18

## Espera, integração local e armazenamento

- **Aguardar até um prazo** pausa o workflow principal por um intervalo ou até uma data com fuso. A fila fica disponível durante a espera. O mesmo ID continua a partir do ponto salvo quando o Servidor Local estiver disponível.
- **Receber webhook local** recebe um POST com JSON e token Bearer. O gatilho salva o disparo na fila e devolve HTTP 202. **Responder ao webhook** entrega o código e o JSON do workflow quando a opção estiver ativa e o resultado ficar pronto em até 10 segundos.
- **Criar tabela do projeto**, **Gravar linhas na tabela do projeto** e **Consultar tabela do projeto** armazenam e recuperam registros JSON por chave de texto no SQLite do workspace.
- **Inserir linhas na tabela do projeto** aceita chaves novas. **Atualizar linhas na tabela do projeto** altera os campos enviados de chaves existentes. **Excluir linhas da tabela do projeto** remove os registros pelas chaves informadas.
- **Projeto → Recursos do projeto → Tabelas do projeto** mostra a chave, a contagem e as linhas de cada tabela do projeto selecionado. **Limpar tabela** exige digitar o nome e remove as linhas para uma nova carga.
- **Excluir tabela** remove a definição e as linhas da tabela local depois da confirmação pelo nome.
- **Deduplicar entre execuções** encaminha chaves inéditas e guarda a marcação pelo prazo escolhido. A marcação acontece ao passar pelo nó e permanece se uma etapa posterior falhar.

Conclua as pendências da versão anterior antes de atualizar. A continuação exige as versões originais dos plugins. Restaurar um backup pausa os gatilhos e encerra as esperas e os webhooks que estavam na fila da cópia. Os dados gravados em tabelas e a memória de deduplicação acompanham o backup do workspace.

# HappyTreeNode 0.1.0-beta.13

- Login opcional nos CRUDs PostgreSQL, com criação local do primeiro administrador por código de uso único e contas individuais.
- Permissões por perfil e cadastro para consulta, inclusão, edição, exclusão e exportação CSV. Acesso aplicado no servidor, inclusive nos seletores e no painel.
- Auditoria por usuário, cadastro e período. As alterações e a auditoria do pedido com itens usam a mesma transação.
- Reexportação com a configuração, as contas e a auditoria preservadas. O exemplo 144 inclui dados fictícios e instruções de homologação.

O exemplo 144 foi homologado. Catálogo com 278 nós, 144 cenários e 226 workflows.

Quem usa a beta.12 pode atualizar em **Conta e licença → Verificar atualizações**. Betas anteriores recebem os pacotes intermediários em sequência. Para instalação nova, use o Setup completo.

Para testar o login no exemplo 144, execute o `Preparar-acesso.sql` no mesmo banco dos dados. Abra `Iniciar.exe` e use o código exibido para criar o primeiro administrador.

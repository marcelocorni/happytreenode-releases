# Instalar HappyTreeNode 0.1.0-alpha.29

1. Encerre o Servidor Local antes de instalar.
2. Execute `HappyTreeNode-Setup-0.1.0-alpha.29-win-x64.exe` em Windows x64, versão 10 build 17763 ou posterior.
3. Abra HappyTreeNode — Cliente pelo menu Iniciar. O instalador inclui runtime .NET, workers e modelos/vozes fixados do Kokoro; não exige SDK, Python ou Node.js instalados separadamente.
4. Consulte o guia Classificação multiclasse e avaliação e os exemplos 111–112.2 no Manual. A busca aceita número e variante.
5. Execute 111 para treinar com dados fictícios, prever e exportar XLSX/detalhes. Em 111.2, selecione o modelo registrado no primeiro exemplo para prever sem treinar novamente.
6. Execute 112 para conferir a matriz de confusão, métricas por classe, barras de F1 e painel HTML. A variante 112.2 compara modelos com duas escolhas de features.
7. Abra o HTML exportado sem internet para explorar os gráficos. Os arquivos contêm os dados da avaliação; confira o conteúdo antes de compartilhar.

## Dados e compatibilidade

Workspace padrão: `%LOCALAPPDATA%\happytreenode\workspaces\principal`. Executáveis: `%LOCALAPPDATA%\Programs\HappyTreeNode`. A pasta antiga n8n-de-pobre não é copiada, migrada ou apagada automaticamente. A desinstalação preserva os dados locais. Faça backup dos seus projetos.

Versão cumulativa: 261 nós, 112 cenários e 179 workflows em 25 plugins. API de plugins 45 e compatibilidade de dados 1. Os 258 nós anteriores e seus modelos permanecem disponíveis. Os quatro exemplos novos foram homologados pelo usuário.

## Multiclasse e limites

Treino local em CPU, com 3 a 20 classes, ao menos oito linhas por classe, até 2.000 linhas e 32 features numéricas. De 20 a 200 iterações. Aproximadamente 20% de cada classe é reservado antes de ajustar normalização e modelo. Valores ausentes, textos numéricos e dados parciais devem ser tratados antes do treino.

Inferência acrescenta ml_classe e ml_score; o score é a maior probabilidade estimada, sem garantia de calibração em dados reais. Use teste independente e rótulos conhecidos no modelo. Matriz: real nas linhas, previsto nas colunas. Macro inclui todas as classes do modelo; divisões sem denominador são zero. Log Loss menor é melhor.

Os resultados sintéticos dos exemplos não indicam o desempenho esperado em uma base real. Limites de memória/CPU/prazo do worker permanecem; GPU e processamento de imagens não fazem parte desta release. Serviço Windows e Assistente de IA continuam adiados.

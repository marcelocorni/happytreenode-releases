# Instalação — HappyTreeNode 0.1.0-alpha.10

## Primeira instalação

1. Baixe `HappyTreeNode-Setup-0.1.0-alpha.10-win-x64.exe` pela release oficial: https://github.com/marcelocorni/happytreenode-releases/releases/tag/v0.1.0-alpha.10.
2. Execute o Setup no Windows de 64 bits e siga as instruções. Os atalhos permitem abrir o Cliente, o Servidor Local e a desinstalação.
3. Inicie o Servidor Local e abra **HappyTreeNode - Cliente**. O endereço local normalmente é `http://127.0.0.1:5078`.
4. Em **Conta e licença**, entre com a conta cadastrada no Portal. O uso exige avaliação ou licença válida. O mesmo usuário pode manter uma sessão ativa do Servidor Local.
5. Abra o projeto **Exemplos HappyTreeNode** e consulte o Manual pelo botão do aplicativo.

## Atualização

Encerre o **Servidor Local** antes de executar o instalador. Fechar apenas o navegador não encerra o servidor. Mantenha a pasta de instalação anterior e siga o Setup; os projetos, arquivos, credenciais e perfis do navegador ficam separados do programa e são preservados.

Se desejar, use o backup do workspace antes da atualização. A restauração do backup é destinada à instalação original; a transferência entre computadores deve usar a exportação/importação de workflows e a reconfiguração dos recursos necessários.

As versões são cumulativas. A alpha.10 inclui os recursos das versões alpha.7 e alpha.8; não é necessário instalar versões intermediárias.

## Conferir o instalador

No PowerShell, execute na pasta do download:

```powershell
Get-FileHash .\HappyTreeNode-Setup-0.1.0-alpha.10-win-x64.exe -Algorithm SHA256
```

Compare o resultado com:

```text
85baf2e2cf0e1942b08385f818fc390a02692a4a6ce6faa3524d333dc924cccc
```

O arquivo tem **295.472.613 bytes**. O checksum e o manifesto da mesma release contêm esses dados.

## Experimentar os painéis exploráveis

Abra os exemplos **49, 50 e 51** e siga as instruções do Manual. Configure o nó **Montar painel explorável** para definir as colunas, os filtros e os componentes do painel. Execute, altere filtros, selecione categorias e confira o recálculo dos indicadores. Reabra o resultado para continuar a exploração ou use **Restaurar visão inicial**.

No exportador HTML, habilite a versão interativa para levar os filtros e cálculos ao arquivo offline. Escolha o tema Claro ou Escuro conforme o resultado desejado. O arquivo inclui os dados das colunas utilizadas; filtros visuais não eliminam os dados distribuídos.

Credenciais e recursos privados não acompanham workflows exportados e precisam ser cadastrados no projeto de destino.

# HappyTreeNode 0.1.0-beta.2

- **Gerar CRUD PostgreSQL** exporta um aplicativo autocontido para Windows x64. Selecione as tabelas de um esquema existente e personalize a lista, os formulários e os relacionamentos simples.
- O aplicativo exportado usa EF Core para consultar, incluir, editar e excluir registros no PostgreSQL. Configure a conexão na pasta do aplicativo. O pacote é gerado sem credenciais.
- No formulário de Pedidos, selecione Cliente e Produto pelo nome. A busca encontra opções além da lista inicial. Ao editar, as escolhas salvas aparecem selecionadas.
- O exemplo **134 — Gerar CRUD de Clientes, Produtos e Pedidos** inclui SQL fictício de preparação e o passo a passo no manual. A versão reúne 274 nós, 134 cenários e 207 workflows de exemplo.

Para atualizar uma instalação, feche o Servidor Local e execute o Setup completo na mesma pasta do programa. Os dados do workspace ficam em uma pasta separada. Para gerar novos aplicativos CRUD com os seletores, use o exemplo 134 ou execute novamente seu workflow de exportação para outra pasta.

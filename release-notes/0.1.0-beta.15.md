# HappyTreeNode 0.1.0-beta.15

- Configuração guiada do Google Drive e Google Planilhas com a credencial OAuth e a cota do projeto Google Cloud de cada usuário.
- Verificação da conta, do serviço e do recurso com diagnóstico de API desativada, escopo, acesso ao arquivo e cota.
- O exemplo 146 consulta os metadados de um arquivo do Drive. O 146.2 lê uma amostra de uma planilha nativa. O guia cria a cópia configurada no projeto atual.
- Manual offline atualizado, Setup completo Windows x64 e atualização incremental da beta.14.

O exemplo 146 e o link **Abrir guia Google** foram homologados. O manual reúne 279 nós, 146 cenários e 230 workflows.

Quem usa a beta.14 pode atualizar em **Conta e licença → Verificar atualizações**. Betas anteriores recebem os pacotes intermediários em ordem. Para uma instalação nova, use o Setup completo para Windows x64.

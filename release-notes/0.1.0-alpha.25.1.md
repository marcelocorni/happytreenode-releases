# HappyTreeNode 0.1.0-alpha.25.1

Diagramas e planejamento visual, com geração local e compartilhamento pelos canais existentes. Inclui a correção de acentos e caracteres especiais homologada no Mermaid.

- **Criar diagrama**: fluxogramas, organogramas, linhas do tempo, sequência e entidades/relacionamentos de bancos, além do modo Mermaid avançado documentado.
- **Criar mapa mental**: tópicos Markdown ou hierarquia JSON, com zoom e ramos recolhíveis. Mapas de objetivos usam o mesmo nó.
- **Montar matriz SWOT**: organize listas e textos nos quatro quadrantes.
- **Montar plano de ação**: use JSON ou tabela com os campos 5W2H, responsável, prazo e situação.
- **Exportar visualização**: HTML independente, SVG, PNG ou PDF, com tema e cores configuráveis. PNG/SVG/PDF usam Edge ou Chrome instalado.
- **Ler esquema do banco**: metadados visíveis à conta em PostgreSQL, MySQL, SQL Server e SQLite, com tabelas, colunas, PK e FK, incluindo chaves compostas. Não consulta registros nem inclui credenciais na saída.

Mermaid 12.3.0 e Markmap 1.0.0 embarcados, sem CDN ou IA. A prévia interativa fica isolada no Studio; as exportações abrem todos os ramos do mapa mental. Textos fornecidos são organizados sem inferência clínica ou recomendações automáticas.

Exemplos **92–97**: diagramas, mapas mentais JSON/Markdown, SWOT, planos a partir de tabelas/respostas e esquema SQLite fictício. As variantes **97.3–97.6** mostram o PNG com WhatsApp, e-mail, Telegram e Discord, usando as contas e os destinos configurados pelo usuário. Manual e LEIA-DIAGRAMAS-PLANEJAMENTO.md atualizados.

O corretivo preserva Unicode e os escapes reservados do Mermaid, mantendo rótulos como texto. Após instalar, execute novamente os workflows afetados para gerar novas visualizações; arquivos e resultados anteriores não são regravados.

Catálogo: **243 nós, 25 plugins, 97 cenários e 147 workflows**, com 20 templates de Landing Pages. API de plugins **43**, compatibilidade de dados **1**. Diagramas 0.1.1 e Database 0.4.0. Versão cumulativa; preserva os recursos anteriores e os ebooks.

Validação da implementação: 165 testes selecionados de backend e 197 testes de interface na candidata inicial; 167 testes selecionados de backend no corretivo. Doze workflows do pacote e onze exemplos conferidos nos dois temas e em computador/celular, incluindo texto final dos SVGs e exportações PNG/PDF. Não foi repetida a suíte unitária do frontend no corretivo. O usuário concluiu a homologação, incluindo os canais WhatsApp, e-mail, Telegram e Discord; o problema de entrega SMTP foi corrigido pelo provedor.

Para instalar, pare o Servidor Local. Setup Windows x64 com dependências e Kokoro incluídos; não requer SDK, Python ou Node.js instalados separadamente. Seus dados e configurações ficam no workspace e não são enviados com o instalador. Consulte INSTALACAO.md.

Esta release não inclui a nova apresentação do Portal, que permanece em revisão separada.

# HappyTreeNode 0.1.0-alpha.13

Conecte APIs com OAuth2, recupere consultas após falhas temporárias e pesquise mensagens no servidor de e-mail.

## Novidades

- **Contas de API OAuth2**: credenciais do aplicativo (Client Credentials) ou autorização pelo navegador com PKCE. Tokens e segredos ficam no cofre do projeto, com renovação antecipada quando suportada pelo serviço.
- **Repetições GET opcionais**: configure novas tentativas para consultas, downloads e paginação, com espera crescente e respeito ao `Retry-After` do servidor.
- **Pesquisar e-mails no servidor**: combine remetente, destinatário, assunto, corpo, datas e estado de leitura e continue a consulta por cursor.
- **Pesquisa IMAP com acentos**: compatibilidade para servidores que recusam Unicode nos critérios de assunto, remetente e destinatário. Os cabeçalhos são conferidos preservando os acentos, sem modificar o estado das mensagens.
- Catálogo com **160 nós, 57 cenários e 78 workflows de exemplo**.

## Exemplos do Manual

- **56 — Consultar API OAuth2 com repetição e gerar painel**: servidor fictício local, autorização, paginação e painel com dois pedidos pendentes, totalizando R$ 3.000.
- **57 — Conferir documentos recebidos por e-mail**: pesquisa, continuação por cursor, leitura das mensagens e cópia dos PDFs anexos para o projeto.

A alpha.13 foi homologada e aprovada pelo usuário após a correção da pesquisa IMAP com acentos. O Manual acompanha os workflows, os dados de demonstração e as instruções.

## Configuração

Em Projeto → Recursos do projeto → Contas de API, cadastre os endpoints e as credenciais do seu serviço. Para autorização pelo navegador, o retorno padrão é `http://127.0.0.1:8401/callback`; registre a URL exata no provedor. O workflow guarda apenas a referência da conta.

Na pesquisa IMAP, `complete=false` indica continuação: use `nextCursor` com os mesmos filtros, pasta e conta, inclusive quando a página estiver vazia. Cada execução trata a página retornada. A compatibilidade de cabeçalhos examina até 500 candidatos por chamada; pesquisa com acentos no corpo depende do suporte do servidor.

As repetições são opcionais e somente para GET. Operações de escrita e envios não são repetidos automaticamente. Uma resposta 401 exige conferir a autorização.

## Instalar ou atualizar

1. Baixe **HappyTreeNode-Setup-0.1.0-alpha.13-win-x64.exe** nos arquivos desta release.
2. Encerre o **Servidor Local** antes de executar o Setup. Fechar a aba do navegador não encerra o servidor.
3. Mantenha a pasta de instalação existente para preservar seus projetos, arquivos, credenciais e perfis de navegador.
4. Abra **HappyTreeNode - Cliente** e entre com sua conta. O uso exige avaliação ou licença válida.

Esta versão é cumulativa. Inclui também os PDFs com senha e calendários da alpha.11, além da regressão e previsão temporal da alpha.12. API de plugins 32; compatibilidade dos dados locais 1.

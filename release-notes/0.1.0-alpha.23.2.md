# HappyTreeNode 0.1.0-alpha.23.2

Atualização cumulativa para Windows x64 com notificações e chatbot por **Telegram e Discord**, usando as APIs oficiais. Quatro nós novos: Notificar e Responder para cada plataforma. Telegram recebe comandos por long polling; Discord utiliza Gateway e o comando nativo `/htn`. Tokens ficam no cofre do projeto; respostas usam a origem autorizada do gatilho.

Inclui gestão de contas de bots: editar preservando o vínculo dos workflows, conservar o token sem exibi-lo, desativar/reativar e excluir com confirmação. Preserva a correção de campos opcionais nulos que impedia envios na alpha.23 inicial. Eventos anteriores com falha ou resultado incerto não são reenviados automaticamente.

O manual detalha criação e instalação dos bots, recuperação do token, permissões, obtenção dos IDs pela API, diferença entre canal e grupo no Telegram e entre servidor e canal no Discord, comandos nativos, usuários autorizados e diagnóstico de falhas. Exemplos 87/87.2 demonstram notificações, 88/89 são simulações locais e 88.2/89.2 são workflows independentes para gatilhos. Telegram e Discord foram testados pelo usuário com seus bots, incluindo menus e consulta de pedidos fictícios; isso não representa homologação de todos os ambientes ou limites das plataformas.

Mantém **233 nós, 23 plugins, 89 cenários e 127 workflows de exemplo**, API de plugins 41 e compatibilidade de dados 1. Preserva integrações Google, WhatsApp, Kokoro com três vozes fixadas, cores dos nós e post-its e os demais recursos cumulativos.

Encerre o Servidor Local antes de instalar. Dados ficam em `%LOCALAPPDATA%\happytreenode\workspaces\principal`; a instalação preserva o workspace atual. A mudança de nome introduzida na alpha.22.3 não migra automaticamente uma base antiga em `n8n-de-pobre`. Configure as contas e os destinos no projeto e consulte o guia Bots no manual antes de ativar um gatilho.
